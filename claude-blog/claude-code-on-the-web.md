# 웹용 Claude Code

- 제품Claude Code

- 읽는 시간5분

업데이트:이제 프리미엄 시트를 가진 Team 및 Enterprise 사용자뿐만 아니라 Pro 및 Max 사용자를 위한 리서치 프리뷰로 웹용 Claude Code를 사용할 수 있습니다. 이러한 사용자에게는 웹의 Claude Code가 기본적으로 활성화되며, 계정 관리자는 Claude 설정에서 액세스 권한을 전환할 수 있습니다. 2025년 11월 12일

오늘 브라우저에서 직접 코딩 작업을 위임할 수 있는 새로운 방법인 Claude Code를 웹에 소개합니다.

현재 베타 버전의 리서치 프리뷰로 제공되며, Anthropic이 관리하는 클라우드 인프라에서 실행되는 Claude에 여러 코딩 작업을 할당할 수 있어, 버그 백로그 처리, 일상적인 수정, 병렬 개발 작업에 이상적입니다.

## 코딩 작업을 병렬로 실행하기

웹의 Claude Code를 사용하면 터미널을 열지 않고도 코딩 세션을 시작할 수 있습니다. GitHub 리포지토리에 연결하고, 필요한 내용을 설명하면, Claude가 구현 작업을 처리합니다.

각 세션은 실시간 진행 상황을 추적하는 독립적인 환경에서 실행되며, 사용자가 Claude가 작업을 진행하면서 과정을 조정하도록 적극적으로 유도할 수 있습니다.

클라우드에서 Claude Code를 실행하면, 이제 단일 인터페이스에서 여러 리포지토리에 대한서로 다른 작업을 병렬로 실행할수 있으며, 자동 PR 생성과 명확한 변경 사항 요약으로더 빠르게 전송할 수 있습니다.

## 모든 워크플로우에 유연하게 대응

웹 인터페이스는 기존 Claude Code 워크플로우를 보완합니다. 특히 클라우드에서 작업을 실행하는 방식은 다음과 같은 경우에 효과적입니다.

- 프로젝트의 운영 방식과 리포지토리 매핑 방식에 대한 질문에 답변

- 버그 수정 및 일상적이고 명확히 정의된 작업

- Claude Code가 테스트 주도 개발을 통해 변경 사항을 검증할 수 있는 백엔드 작업

모바일에서도 Claude Code를 사용할 수 있습니다. 이번 리서치 프리뷰의 일환으로, 개발자가 이동 중에도 Claude와 함께 코딩을 탐색할 수 있도록 iOS 앱에서 Claude Code를 실행할 수 있습니다. 이는 초기 프리뷰 버전으로, 사용자의 피드백을 바탕으로 모바일 경험을 빠르게 개선해 나갈 예정입니다.

## 보안 우선으로 클라우드 실행

모든 Claude Code 작업은 네트워크와 파일 시스템 접근이 제한된 독립적인 샌드박스 환경에서 실행됩니다. Git 상호작용은 보안 프록시 서비스를 통해 처리되며, 이 서비스를 통해 Claude는 승인된 리포지토리에만 접근할 수 있습니다. 따라서 워크플로우 전반에서 코드와 자격 증명을 안전하게 보호할 수 있습니다.

사용자 지정 네트워크 구성을 추가해 Claude Code가 샌드박스에서 연결할 수 있는 도메인을 선택할 수도 있습니다. 예를 들어, Claude가 인터넷을 통해 npm 패키지를 다운로드하도록 허용하면, 테스트를 실행하고 변경 사항을 검증할 수 있습니다.

[엔지니어링 블로그](https://www.anthropic.com/engineering/claude-code-sandboxing)와[문서를](https://docs.claude.com/en/docs/claude-code/sandboxing)읽고 Claude Code의 샌드박싱 접근 방식에 대해 자세히 알아보세요.

## 시작하기

이제 Pro 및 Max 사용자는 리서치 프리뷰로 웹에서 Claude Code를 사용할 수 있습니다.[claude.com/code](http://claude.com/code)를 방문해 첫 번째 리포지토리에 연결하고 위임 작업을 시작하세요.

클라우드 기반 세션은 다른 모든 Claude Code 사용과 속도 제한 사항을 공유합니다. 자세한 내용은[더 알아보기 문서를 살펴보세요](https://docs.claude.com/en/docs/claude-code/claude-code-on-the-web).
