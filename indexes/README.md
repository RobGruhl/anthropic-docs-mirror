## How to Use This Index

### Finding Documentation

1. **Browse by content type** - Start with [Developer Documentation](developer-docs.md), [Engineering Blog](engineering-blog.md), or [Support Articles](support-articles.md) for comprehensive listings
2. **Browse by topic** - Use topic indexes like [Agent SDK](topics/agent-sdk.md) or [Claude Code](topics/claude-code.md) to find related content across all sources
3. **Search with grep** - Use command-line search across all indexes:
   ```bash
   # Search for a keyword
   grep -r "authentication" indexes/
   
   # Search in a specific topic
   grep -i "custom tools" indexes/topics/agent-sdk.md
   ```

### Understanding the Structure

- **Content-type indexes** (developer-docs.md, etc.) - Full document details, source of truth
- **Topic indexes** (topics/*.md) - Lightweight references linking to related documents
- Each document appears fully in ONE content-type index
- Documents may appear as references in MULTIPLE topic indexes
